En este ejercicio, las tres herramientas resultaron complementarias. GitHub Copilot fue útil para las sugerencias y las pruebas; Cursor facilitó los cambios coordinados en varios archivos; y Claude destacó en el análisis de arquitectura y el diagnóstico del stack trace.
